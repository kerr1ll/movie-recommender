# Кино для тебя

Мобильная веб-версия персональной рекомендательной системы из проекта 1.

- Открой `dist/index.html` в браузере для локального запуска.
- `dist/movies.js` содержит 60 фильмов из `../movies.csv`.
- `dist/recommender.js` рассчитывает рекомендации тем же методом контентной фильтрации, что и `../recommender.py`.
- `dist/app.js` связывает поиск, оценки и рекомендации с интерфейсом.

Оценки хранятся в браузере через `localStorage`. У каждого браузера и адреса сайта своя история. Настольная программа хранит оценки в своей базе SQLite.

Веб-версия использует статический HTML, CSS и JavaScript. Сборка и установка пакетов для запуска не нужны.
