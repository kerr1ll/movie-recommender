# Персональная рекомендательная система фильмов

Оцени знакомые фильмы и получи до десяти рекомендаций из каталога на 60 фильмов. Программа работает локально на Python с Tkinter и SQLite.

## Запуск в VS Code

1. В VS Code выбери **Файл → Открыть папку** и открой папку `проект 1`.
2. Открой **Терминал → Создать терминал**.
3. Выполни команду в терминале.

   ```powershell
   python app.py
   ```

## Как пользоваться

1. Найди знакомый фильм по русскому или английскому названию. Выбери его в таблице слева.
2. Нажми кнопку с оценкой от 1 до 5. Для первого опыта поставь «Интерстеллару» 5, если он тебе понравился. Справа сразу появятся кандидаты с похожими жанрами и темами.
3. Выбери фильм справа, чтобы увидеть, какая твоя оценка сильнее всего повлияла на его появление и какие признаки совпали.
4. Оцени ещё несколько фильмов. Чтобы изменить оценку, снова выбери фильм и нажми другую кнопку. Оценки сохраняются после закрытия окна.

## Как работает алгоритм

**Контентная фильтрация** сравнивает характеристики фильмов. Каждый жанр и каждая тема — отдельный бинарный признак. Например, у «Интерстеллара» есть признаки «фантастика» и «космос». У «Марсианина» эти два признака тоже присутствуют.

1. Алгоритм вычисляет **косинусное сходство** между кандидатом и каждым оценённым фильмом. Для бинарных признаков это число совпадений, делённое на квадратный корень из произведения числа признаков двух фильмов. «Интерстеллар» и «Марсианин» делят три признака («фантастика», «приключения», «космос»). Сходство равно `3 / √(6 × 5) ≈ 0,55`.
2. Алгоритм вычитает 3 из оценки и умножает полученный вес на сходство. Оценка 5 даёт вес +2, оценка 3 даёт ноль, оценка 1 даёт −2. Это позволяет учитывать как понравившиеся, так и не понравившиеся фильмы.
3. Алгоритм складывает вклады и делит сумму на сумму абсолютных весов. Кандидаты с положительным итогом попадают в выдачу в порядке убывания. Фильмы, которым ты уже поставил оценку, пропускаются.

В каталоге признаки размечены вручную. Рекомендации зависят от полноты этой разметки и состава каталога.

## Файлы проекта

- `app.py` создаёт окно и связывает действия пользователя с алгоритмом.
- `recommender.py` загружает каталог, хранит оценки и рассчитывает рекомендации.
- `movies.csv` содержит каталог. Новому фильму нужен свободный целочисленный `id`. Жанры и темы внутри поля разделяются знаком `|`.
- `ratings.sqlite3` создаётся при первом запуске и хранит личные оценки.
- `решения.md` содержит план и ключевые решения по проекту.
